# fixtures/ — golden output from real TempleOS

Generated by `tools/gen-fixtures.py` from `tests/full-regression.hc`, run on
real TempleOS under QEMU (a copy of the bundle disk, headless):

- `*.hgs` / `*.hgs.m` — every repo the regression leaves behind (object
  archive + mutable metadata, FORMAT.md v4), byte-for-byte as TempleOS wrote
  them, hex-dumped over COM1 and reassembled on the host.
- `expected.log` — the regression's own serial output (`TFULL_BEGIN` ..
  `TFULL_END`): what each command printed against those repos.
- `TFConfNewer.hgs` is a deliberate 16-byte header claiming format version 9
  (the "newer format rejected" case); it has no `.m` on purpose.

Commit timestamps and hashes differ on every regeneration, so these are
golden *inputs and outputs*, not something to regenerate-and-diff. A second
implementation (e.g. the native port) must read these repos and reproduce the
behaviour in `expected.log`; and repos it writes must pass `check` here.
Regenerate only on a format change: `python3 tools/gen-fixtures.py <bundle.qcow2>`.
